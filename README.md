# DinoyoCraft

Platform reservasi dan penjualan keramik kampung Dinoyo, Malang.

## Stack
- **Frontend**: Next.js 16 (App Router, Turbopack) + React 19 + TypeScript
- **Styling**: Tailwind CSS v4
- **Backend**: Supabase (Postgres + Auth + Storage)
- **Payment**: Midtrans Snap (Transfer Bank, VA, E-Wallet, QRIS)

## Progres Saat Ini
- **Inisialisasi Proyek**: Setup Next.js, Tailwind v4, dan struktur folder.
- **Autentikasi**: Slicing UI Login Admin, Login Mitra, Register Mitra.
- **Halaman Informasi**: Slicing UI Kebijakan Privasi dan Syarat & Ketentuan.

## Cara Menjalankan

### 1. Install Dependencies
```bash
npm install
```

### 2. Jalankan Development Server
```bash
npm run dev
```

Akses `http://localhost:3000`.
